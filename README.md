# Course: SQL for Data Analysis
## Advanced SQL querying techniques
This repository contains my solutions to the exercises from the hands-on, project-based course **SQL for Data Analysis: Advanced SQL Querying Techniques**.
The goal is to practice and showcase advanced SQL concepts applied to common data analysis scenarios.

### How to
The **data** folder contains the SQL statements needed to create and populate the tables used in the exercises. The (1 to 5) SQL files on the root folder cover the different topics of the course: subqueries and CTEs, window functions, functions by data type, data analysis applications and the final project. 

You can run the queries in any SQL RDBMS, with minor adjustments if needed. All notebooks were created and executed on a **Databricks SQL enviroment**.

_This project is shared for learning purposes. Feel free to explore and adapt the queries._
